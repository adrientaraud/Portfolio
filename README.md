## Comment personnaliser

### Photo de profil
Remplace le fichier `assets/images/photo-profil.jpg` par ta vraie photo.
Le nom du fichier doit rester exactement `photo-profil.jpg`.

### CV
Remplace le fichier `assets/cv/CV_Adrien_Taraud.pdf` par ton vrai CV.
Le nom du fichier doit rester exactement `CV_Adrien_Taraud.pdf`.

### Images de projets
Place tes captures d'écran ou visuels de projet dans `assets/images/`
en respectant les noms de fichiers indiqués ci-dessus.

> Si une image n'existe pas, un placeholder s'affichera automatiquement.
